风控与自审查

两项能力都调用 AI 判定「极度政治敏感」内容：群风控撤回群成员的消息，出站自审查拦住机器人自己要发的内容。判定一律走保守策略，宁可漏判也不误判。

AI 费用由机器人主人承担。

每一条送审的消息都会调用一次 AI Agent 的模型（未配置，复用「AI」页全局默认配置文件的 base_url / API Key / 模型），费用记在机器人主人的账号上。开启前请先用下面的黑白名单把范围收紧到自己的群，并留意群消息量。

判定失败、超时或模型未配置时一律放行，不会因为审查让机器人失声。

群风控（group_guard）

正在读取配置文件。

AI 审查

只审查群消息；不阻塞消息管线，判定在后台进行，命中后再撤回。

命中后的动作

撤回需要机器人在群里是管理员，否则只能通知。

撤回命令

引用一条消息并只回复「撤回」两个字（不能带 @）即可触发。撤回别人的消息需要机器人是群管理。

生效范围（黑白名单）

QQ 号和群号一行一个，或用逗号分隔。白名单启用后只在名单内的群生效；黑名单内的群 / 用户永远跳过。

出站自审查（self_review）

正在读取配置文件。

AI 审查

只看文本，但包含解析插件塞进合并转发的全部元信息（标题 / 作者 / 时间 / 简介 / 热评 / 链接）。相同文本命中缓存不会重复计费。

审查范围与动作

合并转发是解析类插件的主要出口，关掉会漏掉大部分元信息。

生效范围（黑白名单）

留空表示审查所有会话。白名单启用后只审查名单内的群 / 私聊用户；黑名单内的会话跳过审查。
